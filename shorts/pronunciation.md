# 낭독 발음 주의 목록 (Supertonic 한국어 TTS)

사용자가 귀로 듣고 지적했거나, 받아쓰기에서 틀리게 나온 말이다. **새 대본을 쓸 때 이 말은 쓰지 않고 오른쪽 말로 바꾼다.**
받아쓰기(ASR)는 억양·발음이 어색해도 맞는 낱말로 알아듣는 경우가 많아서, 이 목록이 ASR 점검을 보완한다.
새로 지적받으면 여기에 한 줄씩 더한다.

| 피할 말 | 문제 | 대신 |
|---|---|---|
| 해변 | 발음이 어색함(사용자 지적, ASR 은 통과) | 바닷가 |
| 닮아 가는 | 연음(달마)이 어색함(사용자 지적, ASR 은 통과) | 비슷해지는 |
| ~가겠지 하는 자기 과신 | “하기 과신”으로 뭉개짐(사용자 지적) | “설명은 과신입니다. 앞으로는 자주 갈 거라고 믿은 거죠.” |
| 일 회 십 달러 | “일에 십 달러” | 한 번에 십 달러 |
| ~달러꼴입니다 | “달러거립니다” | 약 ~달러입니다 |
| 칠천칠백여 명 | “칠천칠백에” | 칠천칠백 명이 넘는 |
| 손님 육십 퍼센트 | “육십”이 빠짐 | 손님의 육십 퍼센트 |
| 질세라 | “질세래” (드문 말) | 지지 않고 |
| 시카고 | “식학(부)”으로 뭉개짐(003 받아쓰기, 두 번 연속) | 지명은 화면에만 쓰고 낭독은 “미국 신문” 등으로 |
| 아메리칸 이코노믹 리뷰에 실린 | “이코노밀 리뷰에 신림” | “경제학자들이 ~했습니다”처럼 학술지 이름은 화면·논문 카드로 |
| 채용에서 | “채용해서” | 채용 과정에 |
| 통계만으로 | “통변으로” | 숫자만 보고 |
| 겨뤄서 | “결어서” | 싸워서 |
| 면책특권 | “면책권”으로 ‘특’이 빠짐(007) | 외교관 면책권 |
| 오대 오케스트라 | “오 퀘스트라”로 뭉개짐(008) | 대표 오케스트라 다섯 곳 |
| 누가 가졌든 | “누가졌든”으로 ‘가’가 빠짐(사용자 지적, 009 — 받아쓰기에도 나왔는데 놓침) | 주인이 누구든 |
| 팔십육 | “육”이 빠져 “팔십”으로 들림(010, 두 번) | 여든여섯(고유어 수) |
| 가입률이 / 납입률과 | ‘률’이 빠짐(010) | ~명 중 ~명 / 저축 비율 |
| 매일 하나씩 (가끔) | “야나씩”으로 ‘매일’이 빠짐(010) | 구독하고, 매일 하나씩 (쉼표) |
| 압수하기 | “앞수기” | 떼어 가기 |
| 안 낸 딱지가 (문장 첫머리) | “안된 딱지가” | 내지 않은 딱지가 |
| 문장 끝 “~ 시장.”처럼 명사로 끝맺기 | “레몬 시험”으로 뭉개짐(005) | “~ 시장입니다.”처럼 서술어로 끝낸다 |

일반 원칙: 같은 소리가 이어지는 구(누가 가-, 하는 자기 -)는 한 소리가 삼켜지므로 피한다.  드문 말·옛말투, 연음·자음동화가 큰 말(닮아, 밟아, 읊어 …), 의존명사(꼴, 여), 한자어 수량(일 회)은 피하고, 짧은 평서문으로 끊는다.
