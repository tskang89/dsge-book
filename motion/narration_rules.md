# 낭독 원고 작성 규칙 (『동태 확률 일반균형 모형』 모션 그래픽 음성용)

입력: `chNN_captions.txt`(장면 원본에서 뽑은 자막 목록, 스크래치 폴더에 만든다) — 화면 자막. `## 장면id — 제목` 줄은 맥락용 머리말, 나머지는 `장면id 번호|자막` 한 줄씩.
출력: `chNN_narration.txt` — **자막 한 줄마다 낭독문 정확히 한 줄**, 같은 키·같은 순서, 형식 `장면id 번호|낭독문`. 머리말(`##`) 줄은 출력하지 않는다.

이 원고는 한국어 TTS(오프라인 음성합성)가 그대로 읽는다. TTS 는 기호·영문·숫자를 제대로 못 읽으므로
**낭독문에는 한글, 공백, 문장부호(. , ? ! · ‘ ’ “ ”)만 남긴다. 라틴 문자, 아라비아 숫자, 수식 기호(= + − / ^ _ $ \ % × ≈ → 등), 괄호는 하나도 남기지 않는다.**

## 1. 내용
- 자막과 **같은 뜻**을 말한다. 내용을 더하거나 빼지 않는다. 길이는 자막을 소리 내어 읽은 길이와 비슷하게(±15%) — 자막 시간에 맞춰 재생되기 때문.
- `$…$` 수식: 짧은 기호·모수값은 소리로 읽는다(`$\sigma=2$` → “시그마 이”). **긴 식을 기호 하나하나 읽지 않는다.** 뜻으로 풀어 말한다.
  예) `$R=\pi/\beta$` → “명목금리는 물가목표를 베타로 나눈 값”, `$(1-\theta)(1-\beta\theta)/\theta$` → “칼보 확률로 정해지는 기울기 계수”처럼 화면의 식을 가리키며 의미로.
  분수는 “베타 분의 일”, “엡실론 피 빼기 일 분의 엡실론 피”보다 “엡실론 피를 엡실론 피 빼기 일로 나눈 값”처럼 듣기 쉬운 쪽을 고른다.
- 변수는 가능하면 **뜻으로** 읽는다: `$\pi_t$` → “인플레이션”, `$y_t$` → “산출”, `$c_t$` → “소비”, `$R_t$` → “명목금리”(자막 문맥에 맞게). 문맥상 기호 이름이 꼭 필요할 때만 기호를 읽는다.
- 시점 첨자: 보통 생략. 필요하면 “티 기”, “다음 기”, “티 빼기 일 기”. `\mathbb{E}_t` → “기대값” 또는 “티 기의 기대”. 모자(hat)·틸드는 읽지 않고 필요하면 “정상상태 대비 편차”, “갭”.
- 괄호 속 말은 자연스럽게 문장에 녹이거나, 순수한 기호 보충이면 뺀다.

## 2. 그리스 문자 (전 장 통일)
α 알파, β 베타, γ 감마, Γ 감마, δ 델타, Δ 델타, ε·ϵ 엡실론, ζ 제타, η 에타, θ 세타, ι 요타, κ 카파, λ 람다, Λ 람다, μ 뮤, ν 뉴, ξ 크사이, π 파이, Π 파이, ρ 로, σ 시그마, Σ 시그마, τ 타우, φ·ϕ **피**(π 파이와 구별), Φ 대문자 피, χ 카이, ψ 프사이, ω 오메가.
아래첨자 붙은 모수: `\phi_\pi` “피 파이”, `\rho_R` “로 알”, `\sigma_\varepsilon` “시그마 엡실론”, `\varepsilon_p` “엡실론 피”, `\lambda_y` “람다 와이”, `\kappa_D` “카파 디”.

## 3. 로마자 한 글자
a 에이, b 비, c 씨, d 디, e 이, f 에프, g 지, h 에이치, i 아이, j 제이, k 케이, l 엘, m 엠, n 엔, o 오, p 피, q 큐, r 알, s 에스, t 티, u 유, v 브이, w 더블유, x 엑스, y 와이, z 제트. 대문자도 같게. 별표(*) 붙은 외국 변수는 “외국의 …” 또는 “… 스타”.

## 4. 숫자
- 한자어로: 0.99 “영 점 구구”, 0.025 “영 점 영이오”, 1.5 “일 점 오”, 0.172 “영 점 일칠이”, 1600 “천육백”, 13.5 “십삼 점 오”, −0.30 “마이너스 영 점 삼”, 1/3 “삼분의 일”, 10^{-14} “십의 마이너스 십사 제곱”.
- % → “퍼센트”, %p → “퍼센트포인트”, ×(배수 계산) → “곱하기”, ≈ → “약”, ~ (범위) → “에서 … 사이” 또는 “부터 … 까지”.
- 세는 말(개, 가지, 나라, 번째 등)은 고유어가 자연스러우면 고유어: 7개 → “일곱 개”, 2개 → “두 개”, 3가지 → “세 가지”. 단위(분기, 년, 장, 배, 기)는 한자어: 3분기 “삼 분기”, 4분기 “사 분기”, 1.5배 “일 점 오 배”, 제5장 “제오장”, 1984년 “천구백팔십사 년”, 2000년대 “이천 년대”.
- 식 번호 (5) → “식 오”, (11)·(12) → “식 십일과 십이”.

## 5. 영문·약어·코드
- 약어는 소리 나는 대로 한글: DSGE 디에스지이, RBC 알비씨, NK 엔케이, HP 에이치피, GDP 지디피, CPI 씨피아이, PPI 피피아이, UIP 유아이피, PCP 피씨피, LCP 엘씨피, DCP 디씨피, PTM 피티엠, CES 씨이에스, CRRA 씨알알에이, MCMC 엠씨엠씨, MH 엠에이치, HPD 에이치피디, SDF 에스디에프, NFA 엔에프에이, TB 티비, CA 씨에이, AR 에이알(AR(1)은 에이알원), IRF 아이알에프, VAR 브이에이알, BK 블랑샤-칸, OLS 오엘에스.
- 고유명사·소프트웨어: Dynare 다이네어, Octave 옥타브, MATLAB 매트랩, Manim 마님, Kalman 칼만. 영어 단어 병기(예: “측정오차(measurement error)”)는 영어를 뺀다.
- 코드 식별자는 소리 나는 대로 띄어 읽는다: steady_state_model “스테디 스테이트 모델”, stoch_simul “스토크 시뮬”, varobs “바 옵스”, estimated_params “에스티메이티드 파람스”, mh_jscale “엠에이치 제이스케일”, dy_obs “디와이 옵스”, rbc.mod “알비씨 점 모드”. order=1 → “오더 일”.
- 인명은 한글 표기(자막에 이미 한글이면 그대로). 영문 인명이면 한글로: Kass and Raftery “카스와 래프터리”, Brooks-Gelman “브룩스 겔만”.

## 6. 검증 (끝내기 전에 반드시)
```python
import re
cap=[l.split('|',1)[0] for l in open('chNN_captions.txt') if not l.startswith('##') and l.strip()]
nar=[l.rstrip('\n') for l in open('chNN_narration.txt') if l.strip()]
assert [l.split('|',1)[0] for l in nar]==cap
bad=[l for l in nar if re.search(r'[A-Za-z0-9=+\-/^_$\\%×≈→⟹⇒<>()\[\]{}~*|]', l.split('|',1)[1])]
print(len(bad)); print("\n".join(bad[:20]))
```
`bad` 가 0개가 될 때까지 고친다(키 부분은 검사 대상이 아님).
